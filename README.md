## 🚀 Deployment on Railway

### Prerequisites
1. Railway account ([https://railway.app](https://railway.app))
2. GitHub repository (this one)
3. PostgreSQL database (Railway provides)
4. Telegram Bot Token from [@BotFather](https://t.me/botfather)

### Step-by-Step Railway Deployment

#### Step 1: Create a New Railway Project
1. Go to [Railway Dashboard](https://railway.app/dashboard)
2. Click **"New Project"**
3. Select **"Deploy from GitHub repo"**
4. Authorize GitHub and select this repository

#### Step 2: Configure Service Type
1. After importing the repo, Railway will detect it as Python
2. **Important:** Change the service type to **"Worker"** (not Web)
   - Workers are ideal for long-running background services like bots
   - They don't expose an HTTP port (bots use long-polling)
3. Set the **Start Command**: `python main.py`

#### Step 3: Add PostgreSQL Database
1. In your Railway project, click **"+Add"**
2. Select **"Database"** → **"PostgreSQL"**
3. Railway automatically generates `DATABASE_URL` environment variable

#### Step 4: Configure Environment Variables
1. Go to **Variables** tab in your Railway service
2. Add the following environment variables:

### Required Environment Variables

```bash
# Telegram Bot Token (REQUIRED)
TOKEN=your_telegram_bot_token_here

# Database URL (auto-generated by Railway PostgreSQL, or override)
DATABASE_URL=asyncpg://user:password@host:5432/dbname

# AI Provider Selection (choose one)
AI_PROVIDER=groq          # Options: groq, openai, anthropic, google
AI_MODEL=mixtral-8x7b-32768

# API Keys (only add for your chosen provider)
GROQ_API_KEY=your_groq_api_key
OPENAI_API_KEY=your_openai_api_key
ANTHROPIC_API_KEY=your_anthropic_api_key
GOOGLE_API_KEY=your_google_generative_ai_key

# Optional: OpenRouter endpoint (if using OpenAI for OpenRouter)
OPENROUTER_API_KEY=your_openrouter_key
```

#### Step 5: Deploy
1. Railway automatically deploys on each GitHub push
2. Monitor logs in **"View Logs"** tab
3. Expected startup message:
   ```
   ✅ Bot live: @your_bot_name (id=123456789)
   ✅ Polling started — Railway deployment healthy.
   ```

#### Step 6: Verify Deployment
- Open Telegram and start a conversation with your bot
- The bot should respond immediately
- Check Railway logs for any errors

## 🐛 Troubleshooting

### "TOKEN env var is not set"
- Go to Railway Variables tab
- Add `TOKEN=your_bot_token`
- Redeploy

### "DATABASE_URL is not set"
- Railway PostgreSQL plugin auto-generates this
- If missing, manually add your database URL
- Format: `asyncpg://user:password@host:5432/dbname`

### "Bot not responding"
1. Check Railway logs for errors
2. Verify TOKEN is correct
3. Ensure service type is **"Worker"** not "Web"
4. Check that `python main.py` is the start command

### "Connection pooling errors"
- Ensure DATABASE_URL has correct asyncpg:// scheme
- Check PostgreSQL is running and accessible
- Verify credentials are correct
